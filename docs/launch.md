# Первый запуск

Для первого пилота сотрудник выгружает из CRM нужные статусы, сроки и подтверждения по ID, добавляет относящиеся к ним сообщения из разрешённых рабочих чатов и проверяет нормализованный JSON без лишних персональных данных.
Python CLI формирует сводку для закрытой рабочей папки отдела, а публичное Pages-демо показывает те же правила только на учебных данных и не служит местом для загрузки рабочей переписки.
Перед действием сотрудник сверяет свежесть выгрузки и первоисточники, проверяет, что слова из чата не выданы за подтверждение CRM, а при расхождении обращается к ответственному и фиксирует результат вручную.
Первую неделю отдел параллельно составляет привычную ручную сводку и сравнивает её с результатом по каждому случаю, записывая пропуски, ложные тревоги, неверные приоритеты и суммарное время подготовки и проверки.
Пилот считаем успешным, если на согласованной выборке нет пропущенных срочных случаев и смешения источников, а медианное суммарное время ниже ручного процесса; при пропуске срочного случая исправляем правило и повторяем сверку.
Только после согласования результатов, SLA и прав доступа с отделом можно подключать реальные источники и ежедневное расписание, оставляя ручную проверку и явное предупреждение при отсутствии или устаревании данных.
