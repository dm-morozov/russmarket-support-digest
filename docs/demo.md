# Демонстрация за 60 секунд

1. 0–15 секунд: откройте Pages, оставьте «Исходный пример» и нажмите «Сформировать сводку»: начать нужно с П-08. CRM и заявления из переписки отображаются раздельно.
2. 15–30 секунд: посмотрите С-24 и С-17: сообщения сотрудников не подтверждают согласование руководителя или комплектность документов. П-09 принят по CRM, количество известно только из чата.
3. 30–40 секунд: выберите «Подтверждение получено» и обработайте снова. В учебном сценарии изменены именно подтверждения CRM, срочных действий больше нет.
4. 40–50 секунд: выберите «Противоречие / нет данных». Три случая требуют проверки; у П-08 сохранён приоритет 1 из-за наступившего срока.
5. 50–60 секунд: измените ID, дату или подтверждение в JSON и обработайте. Затем введите некорректный JSON: появится ошибка, старая сводка не останется на экране.

Расчёт выполняет JavaScript в браузере. Это реальный пересчёт редактируемых данных, без backend и LLM. Совпадение с Python CLI проверяет CI. Ввод не передаётся на сервер и не сохраняется приложением; используйте только учебные данные. Для локального просмотра: `python demo.py`, затем http://127.0.0.1:8765/.
